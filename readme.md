# 데이터분석 입문 (Syllabus)

## 1. 강의 목표
- **Python 프로그래밍** 기본 문법과 실습 역량 습득
- **데이터 분석 전주기 경험**: 수집, 정제, 시각화, 통계분석 등 실습 중심
- **실무 데이터 활용**: 텍스트 및 외부 데이터 가공과 분석, 머신러닝의 기본 이해
- **보고서 및 프로젝트 수행**: 전체 분석 과정을 보고서 및 발표로 총정리
